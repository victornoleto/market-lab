### T3. Escolher feeds pra suprir gaps

Regras:
- **Intraday minute bars (SPY/QQQ/SPX/NDX):**
  - Tier 1: Tiingo IEX 1-min se disponível no plano contratado
  - Tier 2: Polygon.io (REST API, historical minute bars)
  - Tier 3: Databento (pro mas $$) ou Alpha Vantage (free mas limites)
  - Escolher o mais barato que cubra 2007+. Documentar custo + rate limit.
- **BTC/ETH clean daily (sem weekend pollution):**
  - Tier 1: Kraken OHLC historical REST (free, 2013+)
  - Tier 2: Binance historical klines (free, 2017+, maior liquidez)
  - Tier 3: CryptoCompare (mistura de exchanges)
  - Escolher Kraken como primário + Binance como reconciliação.
- **VIX + VIX futures term structure:**
  - Tier 1: Cboe Datashop (pago) ou FRED (VIX spot free, futures limitado)
  - Tier 2: Yahoo finance ^VIX (daily, gratuito, survivorship-OK pra VIX)
  - Tier 3: Tiingo se tiver VIXY/VXX/VXZ (proxies de term structure)
  - Escolher Yahoo/Tiingo combo se não quiser pagar Cboe inicialmente.
- **FX majors (se H6 ou similar estiver na shortlist):**
  - Tier 1: Dukascopy historical tick API (free)
  - Tier 2: OANDA REST historical (demo account gratuito)
  - Tier 3: TrueFX institutional feed

**Se um feed exigir pagamento/assinatura, não assinar sem autorização** —
documentar o custo no audit doc + flag "BLOCKED — user authorization required".
Proceder com Tier-2/3 gratuitos se possível.

Criar scripts em `scripts/data_sprint/`:
