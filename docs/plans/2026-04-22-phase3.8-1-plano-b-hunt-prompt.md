### B4 — Hsieh-Chang-Chen 2025 AR(1) regime filter (PRIOR: MÉDIO-BAIXO novel, Wave 2)

Base: arXiv 2504.20116 (`phase3_7_literature_sprint §T1 paper 1`).

**Tese do paper:** LETF performance é condicional à **autocorrelação dos
retornos**, não à volatilidade absoluta. AR(1)>0 → compounding amplifica
(LETF on); AR(1)<0 → mean-reverting → LETF off.

**Sketch:**
```
lookback = 63  # trading days ≈ 3 months
ar1_t-1 = AR(1) coef fitted on SPY returns over [t-63, t-1]
regime_t = 1 if ar1_t-1 > 0 else 0
leg_t = UPRO/SSO if regime_t == 1 else cash
```

- **Turnover esperado:** ~12-20 trades/ano (AR flips com mais frequência
  que MA-200 regime)
- **Risco:** é o HIGHEST DARF RISK das 4 hipóteses. Se passa, é novo.
  Se falha, fica documentado.
- **Windows:** IS 1970-1999 / OOS 2000-2015 / FWD 2016-2026
