# US Momentum 13612 Outputs

This folder groups US-universe outputs by universe so the study root can keep only
shared code, specs and top-level reports.

## Files

- `base_results.json`: machine-readable results from the initial `us_all` base
  run across stocks, ETFs and mixed universes.
- `stocks/`: US stocks-only base plots and extensive-grid evidence.
- `etfs/`: US ETF base plots and staggered-offset evidence.
- `mixed/`: US mixed-universe base plots.
