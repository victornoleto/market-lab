# books/ — Books Knowledge Base

This folder contains the **34 absorbed books** that feed the ai-trade
"trading expert" (Phase 0 of [`../ROADMAP.md`](../ROADMAP.md), **done**).

Pipeline:
`raw/<slug>.pdf` → `extracted/<slug>/` → `summaries/<slug>.md` (9 sections with
mandatory `[p.X]`/`[ch.Y]` citations) → `../knowledge/SKILL.md` (aggregator
Claude Skill, generated by `../scripts/build_skill.py`).

## Structure

```
books/
├── raw/              # PDFs with canonical slugs (inventory in MAPPING.md)
├── extracted/        # extracted text + chapters + metadata (gitignored)
├── summaries/        # 1 validated MD per book (versioned; gate via validate_summary)
├── code/             # complementary C++ code from Timothy Masters' zips
│   ├── masters-assessing/         # Assessing and Improving Prediction (no PDF)
│   └── masters-testing-tuning/    # complements testing_tuning.pdf
├── MAPPING.md        # canonical "original name → slug" inventory (generated by rename_books.py)
└── README.md         # this file
```

> **PDF compression in `raw/`:** `../scripts/compress_pdfs.py` exists and
> tries to shrink PDFs via Ghostscript, but **only replaces the original
> if the extracted text (via pymupdf) is word-for-word equivalent**. In
> practice, Ghostscript re-renders text streams (normalises uppercase,
> joins spaces, swaps ligatures) and the script rejects. If you need real
> gains on large files (e.g. `evidence_based_ta.pdf`, `cycle_analytics.pdf`),
> the next step is a `pikepdf`-based recompressor that touches only image
> XObjects — out of scope until needed.

## Pipeline (how to reproduce / re-absorb)

Prerequisite: `.venv/` active with deps (`uv sync` at the root). Scripts in `../scripts/`.

### Re-absorb ONE book

```
/absorb-book <slug>
```

Triggers the `book-reader` subagent (in `../.claude/agents/book-reader.md`)
over `extracted/<slug>/`, rewrites `summaries/<slug>.md` and validates via
3 layers (structural + deterministic + 2 adversarial judges with
self-consistency).

### Bulk absorb

```
/absorb-all-books
```

Triggers parallel waves of 2-3 agents (via
`superpowers:dispatching-parallel-agents`). Books with an incomplete PDF
are skipped automatically (no `_metadata.json`).

### Validate

```bash
../.venv/bin/python ../scripts/validate_summary.py --all
../.venv/bin/python ../scripts/check_citations.py <slug>    # per book
```

Rules: ≥80% of assertions with `[p.X]`/`[ch.Y]`; 9 sections present
(`N/A — <reason>` counts as present); metadata with author and year.

### Regenerate the Skill

```bash
../.venv/bin/python ../scripts/build_skill.py
```

Deterministic (zero LLM calls). Populates `../knowledge/`:
- `SKILL.md` (master — frontmatter + inviolable rules + index)
- `books/` (copy of the 33 validated summaries)
- `strategies/`, `indicators/`, `validation/` (thematic aggregations)

### Before any re-absorption: Tier 2

Run **once per book** to generate `_page_index.json` (deterministic
PDF↔printed offset — eliminates the largest class of book-reader retries):

```bash
../.venv/bin/python ../scripts/build_page_index.py <slug>
```

## Troubleshooting

**`extract_pdfs.py` raises `ScannedPDFError`**
- The PDF has no text layer (it is a scanned image).
- Replace with an OCR'd version and re-run. Pipeline is idempotent.

**`extract_pdfs.py` raises `IncompleteBookError`**
- PDF has <50 pages and no TOC → probably front matter / preview.
- Replace with the full book. Same, idempotent.

**`validate_summary.py` returns FAIL**
- Read the output: low citation ratio or missing section.
- **Do NOT edit the summary manually.** Re-trigger the agent with specific
  feedback (e.g. "section 3 has 4 formulas without citations, fix it").

**`check_citations.py` reports mis-citations**
- Almost always a PDF↔printed offset. Run `build_page_index.py <slug>`
  first; then re-trigger `/absorb-book <slug>` if the index ends up very
  different from the one used in the original absorption.

**Book-reader blows context on a large book**
- `_metadata.json` should have marked `recommended_mode: "map_reduce"`.
- If it didn't, tune the threshold in `../scripts/extract_pdfs.py`
  (currently 400K estimated tokens to activate map-reduce).
