# MyFxBook v4 task 003 — PBO/CSCV gate de overfit pronto

**2026-05-04** — Task 003-cpcv-pbo do redesign do pipeline myfxbook entregou o
modulo `studies/myfxbook_reverse_engineering/shared/cpcv.py` com PBO via CSCV
(`[advances_fin_ml, p.208-222]`).

## O que e

PBO (Probability of Backtest Overfitting) responde: "se eu testei N candidate
rules e escolhi a melhor in-sample, qual a probabilidade de ela ter sido
sorte e ranquear abaixo da mediana out-of-sample?". CSCV (Combinatorial
Symmetric Cross-Validation) parte a janela em S sub-periodos, enumera todos
os splits S/2 train + S/2 test simetricos (total `C(S, S/2)/2` paths), e mede
a fracao de paths em que a "melhor in-sample" colapsa OOS.

Mandate §2.4 declara `PBO < 0.5` como hard gate; PBO >= 0.5 = mais provavel
sorte que edge real `[advances_fin_ml, p.211]`. Antes desta task, o gate
existia no papel mas nao tinha implementacao usavel pelo pipeline myfxbook
(o `src/ai_trade/backtest/grid/gates.py` e do ramo Plano A DORMANT).

## Validacao com 3 cenarios sinteticos textbook

| Cenario | PBO | Veredito |
|---|---:|---|
| Estrategia 0 dominante consistente (Sharpe 2.0 estavel) | **0.000** | PASS — gate libera edge real |
| Pure noise iid N(0,1) | **0.509** | FAIL — gate pega ruido |
| Spike rotativo (best-in-sample muda em cada sub-periodo) | **1.000** | FAIL — gate pega overfit adversarial |

Todos os tres sao S=16, n_paths=6435. Comportamento esperado.

## Esclarecimento de escopo

Foi tentador no review GPT-5.5 colocar PBO como SUBSTITUTO do walk-forward.
Esta tentativa entrou em `DEAD_ENDS.md` como rejeitada: PBO mede sorte na
selecao entre N candidates; WF mede generalizacao temporal de UMA regra.
Sao complementares e mandate §2.4 exige AMBOS como hard gates. A task 004
(proxima sessao) refatora `shared/gates.py` para enforcar os dois.

## Onde isto entra no pipeline

- Task 015 (LightGBM miner) produz N candidate rules sobre o trade history
  do EA.
- Helper `build_metric_matrix_from_candidates(candidates, trades, ohlc,
  n_groups=16)` monta matriz `(S, N)` de Sharpe-per-rule-per-sub-periodo.
- `cscv_pbo()` consome a matriz e devolve PBO + CI 99% bootstrap +
  diagnostico `median_oos_rank_of_best_is`.
- Task 004 wira essa chamada em `gates.py.passes_mandate_24()`.
